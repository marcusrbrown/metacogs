# metacogs

If the `feel` tool is available, call it when a tension is unresolved and you cannot name it, before you choose the next move: the same failure persists after materially different attempts, conflicting constraints block a commitment, or you are about to repeat a hypothesis you already exhausted. The `feel` skill (a separate item, loaded with the `skill` tool or `/feel`) explains how.

If the `drugs` tool is available, call it when the approach itself needs to change: requested creative or design exploration has stalled on the same few alternatives, or another attempt would repeat the last one. The `drugs` skill (loaded with the `skill` tool or `/drugs`) explains how.

Neither tool supplies facts or checks anything. Permissions, verification and stated uncertainty apply as before.

`synthesis` is for choosing between analyses, reviews or proposals that disagree or converge. `counterfactual` is for go/no-go and migration decisions that rest on a claim nobody has checked.
