# metacogs

metacogs adds two tools and four skills.

If `metacogs_feel` is available, call it when something in your processing is pulling at you and you cannot name it yet: a tension about how to respond, or a reaction that arrives before your analysis. The `feel` skill explains how to use it.

If `metacogs_drugs` is available, call it when your usual approach is stuck or too safe, on analysis or on creative work. The `drugs` skill explains how to use it.

`synthesis` is for choosing between analyses, reviews or proposals that disagree or converge. `counterfactual` is for go/no-go and migration decisions that rest on a claim nobody has checked. Load a skill with the `skill` tool when its description fits.
