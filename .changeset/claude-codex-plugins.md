metacogs now ships a Claude Code plugin and an experimental Codex plugin, installable from this repository's marketplaces. Both add the `feel` and `drugs` tools and the four skills. The Claude Code plugin also adds a session-start note that can be switched off; the Codex plugin has no note, because Codex discards hooks from this plugin format. Neither has been installed and run on a real host yet.
