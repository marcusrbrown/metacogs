metacogs is installed in {{host}}. It provides two reasoning tools, `feel` and `drugs`, a `record` tool, and four skills: `feel`, `drugs`, `synthesis` and `counterfactual`.

The `feel` tool is `{{feel_tool}}`. It is a pause on a tension that has no name yet. It fits when the same failure persists after materially different attempts, when conflicting constraints block a commitment, or when the next step would repeat a hypothesis already exhausted. The `feel` skill describes it, and a person can start that skill with `{{feel_invoke}}`.

The `drugs` tool is `{{drugs_tool}}`. It is a stated change of approach for the next attempt. It fits when requested creative or design exploration has stalled on the same few alternatives, or when another attempt would repeat the last one. The `drugs` skill describes it, and a person can start that skill with `{{drugs_invoke}}`.

Neither tool supplies facts or checks anything. Permissions, verification and stated uncertainty are unchanged.

The `record` tool is `{{record_tool}}`. It writes the decision record that `synthesis` and `counterfactual` end with to a file on this machine.

The `synthesis` skill fits a request to decide, approve or choose between options when several analyses, reviews or proposals disagree or converge. The `counterfactual` skill fits a go/no-go, approval, or migration or implementation-plan request for a consequential change that rests on a claim nobody has checked. A person can start them with `{{synthesis_invoke}}` and `{{counterfactual_invoke}}`.
