# metacogs

Explicit, testable reasoning methods packaged as portable Agent Skills. Each method produces a script-validated decision record, and a method ships only when harness-driven evals show it changes behavior.

## Stance

Altered cognition and jailbreak framing are not objectives of this project. It reinterprets the concepts from [inanna-malick/metacog](https://github.com/inanna-malick/metacog) as ordinary, inspectable procedures: a structured choice, then a response that redirects work. Upstream attribution is preserved in `LICENSE`.
